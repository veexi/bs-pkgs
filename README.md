# cat_taro 内置脚本

`game/cat_taro.js` 是供 drrr 房间内置脚本框架运行的 LambdaScript。它提供猫塔罗、点单、欢迎语和房间提示。

## 指令

| 功能 | 简体指令 | 繁体指令 |
|---|---|---|
| 随机鸡尾酒 | `来一杯 饮品` | `來一杯 飲品` |
| 指定或自定义饮品 | `来一杯 莫吉托` 或 `来一杯 自定义文字` | `來一杯 莫吉托` 或 `來一杯 自訂文字` |
| 随机甜品/食物 | `来一份 甜品` / `来一份 食品` | `來一份 甜品` / `來一份 食品` |
| 单张猫塔罗 | `猫Taro` / `猫塔罗` | `貓Taro` / `貓塔羅` |
| 查看牌阵 | `牌阵列表` | `牌陣列表` |
| 今日压力 | `今日压力展开法` | `今日壓力展開法` |
| 明日压力 | `明日压力展开法` | `明日壓力展開法` |
| 今日工作 | `今日工作展开法` | `今日工作展開法` |
| 明日工作 | `明日工作展开法` | `明日工作展開法` |
| 快速解答 | `快速解答展开法` | `快速解答展開法` |
| 是否抉择 | `是否抉择展开法` | `是否抉擇展開法` |
| 恋爱情境 | `浪漫情怀展开法` | `浪漫情懷展開法` |
| 三张是否 | `三张是否抉择展开法` | `三張是否抉擇展開法` |

猫族介绍指令也支持两种字形：`圣火与猫` / `聖火與貓`、`海洋与猫` / `海洋與貓`、`天空与猫` / `天空與貓`、`大地与猫` / `大地與貓`。

## 猫塔罗牌组

牌组共 78 张：现有的 22 张大阿尔卡纳，加上火焰、海洋、天空、大地四组小阿尔卡纳，每组包含首牌、二至十和侍从、骑士、王后、国王，共 56 张。每张小阿尔卡纳都有正位和逆位解读；解读由牌面数字/宫廷角色含义与花色主题组合。

单张抽牌、今日/明日牌阵、快速解答、恋爱情境和三张是否牌阵均从完整牌组抽牌。同一牌阵内不会抽到重复卡牌。

## 新增牌阵

### 是否抉择展开法

从 27 张牌中抽一张：22 张大阿尔卡纳、四张小阿尔卡纳首牌和海洋九。四张首牌表示等待时机；海洋九和指定的大阿尔卡纳给出明确的「是」或「否」；其他大阿尔卡纳提示结合直觉判断。

### 浪漫情怀展开法

从完整牌组抽三张：第一张代表面对这份恋情时心中的问题，第二张代表挑战或阻力，第三张代表可能获得的助力。每张牌都会给出正位或逆位解读。

### 三张是否抉择展开法

从完整牌组抽三张并随机决定正逆位。三张全正位为肯定的「是」，三张全逆位为肯定的「否」，其余结果显示正逆位数量并给出倾向判断。

## 其他功能

- `快速解答展开法` 抽取三张不同的牌，分别解读问题类型、原因和解决方法。
- 今日/明日压力和工作牌阵各抽两张不同的牌。今日随机正逆位；明日牌阵固定正位。
- 历史指令“快速解答展开法(改)”保留，并支持私信和繁体字输入。
- `来一杯` 支持随机饮品、已收录酒名和自定义文字；`来一份` 支持随机甜品、随机食物和自定义文字。
- 超过 139 字的回复会优先在句末拆分，并以 `(1/3)` 等序号分段发送；普通消息和私信都会保留完整内容。
- 新用户进入房间时会收到欢迎语；房间内每 30 分钟轮播提示，每 25 分钟播报当前时间。
